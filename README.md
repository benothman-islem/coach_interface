# Espace coach

Application Flutter présentant les quatre écrans du coach : Accueil, Séances,
Adhérents et Profil. Elle démarre directement sur Accueil et utilise des
données locales de démonstration ; aucune connexion ni configuration Firebase
n'est nécessaire.

## Développement

```shell
flutter pub get
flutter run
```

Les données de démonstration permettent de consulter les adhérents, gérer les
séances et modifier le profil pendant l'exécution.

## Vérification

```shell
flutter analyze
flutter test
```
